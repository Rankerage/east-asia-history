## 🏛️ 수도 (Capital Cities)

### 평양 (平壤)
- **한자**: 平壤 / 平壤城
- **영문**: Pyongyang
- **좌표**: 39.0300, 125.7500
- **현대지명**: 북한 평양직할시
- **시대**: 고조선(후기), 고구려(후기·장수왕~멸망), 고려(서경), 조선
- **고지도**: 대청광여도 평안도, 대명여지도
- **사료**: 삼국사기 지리지 "평양은 본래 삼조선의 땅", 고구려본기 "장수왕 15년(427) 평양 천도"
- **책고보**: 고조선의 중심지는 요동이며 평양은 후기 수도. 고구려 평양천도는 남진정책의 일환.
