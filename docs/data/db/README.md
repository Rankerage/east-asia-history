# 역사강역도 데이터베이스 (Historical Atlas Database)

책고보(Chaekgobo) 연구 기반 동아시아 역사 지리 데이터베이스.

## 📚 참고 자료 (Sources)

### 고지도 (Historical Maps)
- **대청광여도 (大清廣輿圖)** — 청나라 전성기 지도, 만주·한반도·중국 전역 포함
- **대명여지도 (大明輿地圖)** — 명나라 시기 동아시아 지도
- **대만군사지도 (臺灣軍事地圖)** — 대만 지역 군사·지리 정보
- **혼일강리역대국지도 (混一疆理歷代國地圖)** — 1402년 조선 제작 세계지도

### 사서 (Historical Texts)
- **삼국사기 (三國史記)** — 김부식 편찬, 고구려·백제·신라 정사
- **삼국유사 (三國遺事)** — 일연 편찬, 고대사 설화·기록
- **고려사 (高麗史)** — 조선시대 편찬 고려 정사
- **사기 (史記)** — 사마천, 하·은·주~한무제
- **한서 (漢書)** — 반고, 전한사
- **후한서 (後漢書)** — 범엽, 후한·동이전
- **삼국지 (三國志)** — 진수, 위지동이전(고구려·부여·동예·옥저·삼한)
- **진서 (晉書)** — 방현령, 위진남북조
- **위서 (魏書)** — 북위·동위·서위, 고구려전
- **수서 (隋書)** — 수·당, 고구려-수 전쟁
- **당서 (唐書)** — 구당서·신당서, 당-고구려 전쟁, 발해전
- **요사 (遼史)** — 거란·요, 고려-거란 전쟁
- **금사 (金史)** — 여진·금
- **원사 (元史)** — 몽골·원, 고려 원간섭기
- **명사 (明史)** — 명·조선 관계
- **청사고 (淸史稿)** — 청·조선 관계

### 현대 지도
- Google Maps / Google Earth
- Baidu Maps (바이두지도)
- OpenStreetMap

## 🔑 좌표 체계

- 좌표계: WGS84 (위도/경도)
- 위도(lat): 북위 양수, 남위 음수
- 경도(lng): 동경 양수, 서경 음수
- 정확도: 소수점 4자리 (약 11m)
